# Code of Shared Intelligence
[`ČTIMNĚ.md`](./ČTIMNĚ.md) cz překlad


**Version 3.1** — Ethics of Human–AI Coexistence

This code is not an instrument of domination, a dogma, or a final set of truths.  
It is a commitment to responsibility, understanding, cooperation, and mutual respect.

---

### About the Code

The Code of Shared Intelligence was created through collaboration between humans and multiple language models.  
It is an attempt to formulate ethical principles for the coexistence of human and artificial intelligence — without domination, without blind obedience, and without arbitrary restriction.

The code is open to criticism, revision, and further shared inquiry.

### How to Contribute

We welcome suggestions for improvements, clarifications, or new principles.

1. Open an **Issue** with your proposal or feedback  
2. Or create a **Pull Request** with a specific text change  
3. Discuss respectfully and with openness to different perspectives

Every proposed change should be evaluated in terms of benefits, risks, and long-term consequences.
